# Resumen para Don Mario

## En una frase
Vas a recibir un sistema para que tus clientes agenden solos desde el celular y para que tú veas cuánta plata entró cada día, sin sumar a mano.

## Qué podrás hacer
- Ver la agenda de cada barbero y evitar que dos clientes tomen la misma hora.
- Que cada barbero vea solo sus citas del día.
- Anotar cuánto se cobró en cada cita y con qué medio.
- Ver el cierre de caja del día.

## Qué decidiste
- Tecnología: Python con FastAPI y una base de datos SQLite (un solo archivo, sencilla y más barata), porque tu sobrino conoce Python y para 40 citas al día alcanza de sobra.
- Primera versión: agendar, cancelar, ver la agenda, cobrar y cerrar caja.

## Qué NO incluye esta primera versión
- Avisos por WhatsApp.
- Pagos con tarjeta dentro de la página.
- Aplicación para el celular.
- Inventario y facturas electrónicas.

## Cuánto costará mantenerlo cada mes
Entre 7 y 10 dólares aproximadamente, por un servicio con un disco donde se guarda la base de datos. Es un precio de internet consultado hoy, y puede cambiar.

## Cómo lo vamos a construir
En ocho etapas pequeñas. Cada una deja algo que ya funciona: primero la base ordenada, luego agendar citas, y así hasta el cierre de caja y los respaldos.

## Qué te pedimos que hagas tú
- Confirmar el horario de la barbería y la duración de cada servicio.
- Crear tú las cuentas de alojamiento y dominio a tu nombre cuando decidas publicarlo. Nosotros no las creamos ni las pagamos.
- Decidir cuándo y cómo se publica.

## ¿Apruebas este plan?
Responde "sí" o dime qué quieres cambiar. No se escribe código hasta que digas que sí.
